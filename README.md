## Cómo colaborar
1. Crear un Issue describiendo la mejora o problema.
2. Crear una rama a partir de `main` siguiendo la convención:
   `git switch -c feature/nombre-de-la-funcionalidad`
3. Realizar los commits con mensajes claros y descriptivos.
4. Subir los cambios:
   `git push -u origin feature/nombre-de-la-funcionalidad`
5. Abrir un Pull Request hacia `main` detallando las modificaciones para su revisión y posterior integración.
